Install a provider in CloudStream

  1. Open a provider card and choose CS3 for the published CloudStream package.
  2. Use JAR where the build pipeline publishes one.
  3. Use the repository manifest when your CloudStream setup supports repository installation.

The directory only exposes artifacts listed by the automated build index, so the UI does not invent download URLs.
