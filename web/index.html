QUICK START

Install a provider in CloudStream

  1. Open a provider card and choose CS3 for the CloudStream plugin package, or choose Media Player to open that provider’s source map and player.
  2. The JAR control is functional: when no real JAR exists it opens the artifact explanation instead of acting like a dead link.
  3. Use Media Player with an authorized direct MP4/HLS source. The provider source map remains visible beside the player.

CloudStream uses the published CS3 package. The streaming workspace below each provider uses repository-derived source details and an optional direct-media player; provider pages are never loaded in an iframe.

ABOUT MOVIECLOUD

Your Movie-Flick collection + streaming workspace.

The web app is a lightweight static frontend: no framework, no backend, no tracking dependency. Provider metadata, artifact links, streaming endpoints and icons are defined in JavaScript. The UI validates artifacts in the browser and provides a per-provider streaming workspace with search/watch tools where supported.
