Install a provider in CloudStream

  1. Choose CS3 on a provider card to download the generated CloudStream package.
  2. Open Details to inspect source ownership, capabilities and build metadata.
  3. Use Media Player only with an authorized direct MP4/HLS URL whose host is configured in the gateway allowlist.

The static Pages app never executes Android/Kotlin extractors in the browser. It remains useful as a directory and authorized-media shell while CloudStream handles provider extraction.

ARCHITECTURE

One source of truth.
Three production layers.
