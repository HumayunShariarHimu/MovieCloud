QUICK START

Install a provider in CloudStream

  1. Open a provider card and choose CS3 for the CloudStream plugin package, or choose Media Player to open that provider’s source map and player.
  2. The JAR control is functional: when no real JAR exists it opens the artifact explanation instead of acting like a dead link.
  3. Use Media Player for repository-declared direct sources, an optional M3U/M3U8 playlist URL, or an authorized direct MP4/HLS source. The provider source map remains visible beside the player.

CloudStream uses the published CS3 package. The streaming workspace below each provider uses repository-derived source details, repository-declared automatic sources when available, optional M3U/M3U8 playlists, and an authorized direct-media player; provider pages are never loaded in an iframe.

ABOUT MOVIECLOUD

Your Movie-Flick collection + streaming workspace.

The web app is a lightweight static frontend with a small Vercel media gateway. Provider metadata, artifact links, source maps and icons are defined in JavaScript. The UI validates artifacts and provides a responsive per-provider streaming workspace.
