QUICK START

Install a provider in CloudStream

  1. Open a provider card and choose CS3 for the CloudStream plugin package.
  2. Use JAR where available for the Java plugin artifact.
  3. In CloudStream, install the downloaded plugin or add the repository URL when your setup supports repository manifests.

Build artifacts are served from the builds branch of your MovieCloud repository. The source repository is separate from the artifact branch.

ABOUT MOVIECLOUD

Your Movie-Flick collection, organized.

The web app is a lightweight static frontend: no framework, no backend, no tracking dependency. Provider metadata, artifact links and icons are defined in JavaScript, while the UI can validate artifact availability from the browser and lets you copy direct URLs.
